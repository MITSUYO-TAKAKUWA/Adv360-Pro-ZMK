## How to record new work
1. Check existing archive and current repo state; avoid duplicating an earlier study.
2. Save the full shareable research under `docs/research/YYYY-MM-DD-topic.md`, with primary links, methods, limitations, and user-approved vs merely proposed decisions.
3. Update this index, create a documentation branch, open a Draft PR, and report exact path/commit/PR.
4. Never disclose tokens, personal data or copyrighted material without redistribution rights; never change product or production systems just to archive research.
5. If a chat lacks GitHub access or the source file, report **NOT SAVED** and leave a complete handoff. Repository instructions cannot force unconnected ChatGPT Deep Research to execute GitHub writes.
